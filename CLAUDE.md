# CLAUDE.md

Guidance for Claude Code in this repo.

## Project status (Custom View)

Mati follows progress through the **"Project status"** Custom View artifact:
https://claude.ai/artifact/EmtDCmLQ9xWqUo8YqspRiy

- When you start non-trivial work, add the plan to the artifact (what you will do, in which repo).
- Update it as you go: what is done, in progress, blocked, and the PR links.
- When you finish, mark the work as done and note anything Mati must review or decide.
- Keep entries short and easy to scan. Never put secrets or credentials in it.
